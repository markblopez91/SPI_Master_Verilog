# SPI Master in Verilog

SPI Master implemented in Verilog and simulated using Vivado 2021.2.

## Features

* SPI serial communication
* Master mode operation
* Behavioral simulation
* Testbench verification
* Waveform analysis

## Tools

* Verilog
* Vivado 2021.2
* Arty A7-100 FPGA board

## Files

* spi_master.v
* spi_master_tb.v
* simulation waveform screenshot
